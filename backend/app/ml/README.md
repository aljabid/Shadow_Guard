# ShadowGuard Threat Classification Engine

Isolated, additive ML package — safe to delete without affecting any other part of the application.

## Architecture

```
backend/app/ml/
├── __init__.py                        # Package marker
├── README.md                          # This file
├── data/
│   └── training_messages.csv          # ~245 labelled examples (7 classes)
├── artifacts/                         # Generated by train.py (not in git)
│   ├── threat_model.joblib
│   └── metrics.json
└── threat_classifier/
    ├── __init__.py
    ├── labels.py                      # Canonical class labels
    ├── features.py                    # Text pre-processing
    ├── fallback.py                    # Fallback response when model absent
    ├── classifier.py                  # ThreatClassifier class + CLI
    ├── train.py                       # Training script
    └── validate.py                    # Validation / report script
```

## Classes

| Label | Description |
|-------|-------------|
| `dropper_recruitment` | Card dropper / money mule recruitment |
| `exchange_complaint` | Crypto/fiat exchange fraud complaint |
| `pyramid_promo` | Investment pyramid / Ponzi promotion |
| `gambling_promo` | Illegal online gambling advertisement |
| `contraband_sale` | Drug / unlicensed vape / alcohol sale |
| `leak_sale` | Stolen data / database leak for sale |
| `normal` | Benign / unrelated message |

## Quick start

```bash
cd backend

# 1. Install dependencies (if not already installed)
pip install scikit-learn pandas joblib

# 2. Train the model
python -m app.ml.threat_classifier.train

# 3. Validate
python -m app.ml.threat_classifier.validate

# 4. Classify a single message
python -m app.ml.threat_classifier.classifier "Нужны дропы, платим 10%"
```

## API endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/v1/ml/status` | Model status and metrics |
| POST | `/api/v1/ml/classify` | Classify a text message |

### POST /api/v1/ml/classify

Request:
```json
{ "text": "Нужны дропы, платим 10%" }
```

Response:
```json
{
  "label": "dropper_recruitment",
  "confidence": 0.9312,
  "scores": {
    "dropper_recruitment": 0.9312,
    "exchange_complaint": 0.0088,
    "pyramid_promo": 0.0201,
    "gambling_promo": 0.0051,
    "contraband_sale": 0.0147,
    "leak_sale": 0.0063,
    "normal": 0.0138
  },
  "fallback": false
}
```

## Rollback

Delete `backend/app/ml/` entirely. The application will continue running.
The two lines added to `router.py` will fail silently because the API file is gone — remove them too.
